# Nota acadêmica e limites de divulgação

## Finalidade

Este documento identifica o repositório como uma publicação técnica de apoio ao projeto universitário **Dvorah — Motor de Divulgação IA**. O objetivo é permitir que professores, colegas e outros estudantes compreendam o escopo da aplicação sem confundir o laboratório com o relatório acadêmico integral.

## O que está sendo publicado

Este repositório publica:

- o código-fonte do laboratório web;
- o modelo didático de simulação;
- a documentação do método;
- a referência de identidade visual utilizada na interface;
- as instruções de execução e reutilização.

## O que não está sendo publicado

O relatório em PDF associado à avaliação acadêmica **não faz parte deste repositório**. Ele está sendo utilizado apenas como base interna para estruturar esta extensão e permanece reservado para a entrega acadêmica prevista.

Também não são publicados neste repositório:

- documentos avaliativos completos;
- dados pessoais ou credenciais;
- métricas privadas de plataformas;
- materiais autorais não autorizados;
- resultados apresentados como evidência real quando forem apenas projeções.

## Classificação do artefato

A aplicação deve ser lida como um **artefato experimental e didático**. Ela demonstra como uma proposta teórica pode ser convertida em um ambiente de teste contínuo, com parâmetros editáveis e registro de aprendizagem.

O valor acadêmico está principalmente na estrutura do método:

1. formulação de hipótese;
2. definição de variável ou indicador;
3. simulação de cenários;
4. execução ou observação externa;
5. registro do resultado;
6. decisão de manter, adaptar ou arquivar;
7. novo ciclo de aprendizagem.

## Responsabilidade sobre os dados

A aplicação utiliza dados simulados para demonstrar o funcionamento das fórmulas. Esses dados não devem ser citados como desempenho real do projeto musical. Para uma avaliação empírica, os números precisam ser substituídos por registros verificáveis, com data, plataforma, janela de coleta e definição operacional da métrica.

## Relação com o trabalho universitário

O repositório é uma extensão prática e reutilizável do estudo, mas não substitui a entrega acadêmica nem representa, sozinho, a totalidade da pesquisa. A leitura adequada é:

> **relatório acadêmico reservado + laboratório web público como demonstração técnica controlada.**

## Reutilização por outros estudantes

A estrutura pode ser adaptada para outros projetos, desde que cada adaptação:

- declare sua autoria e instituição, quando aplicável;
- diferencie dados observados, estimados e simulados;
- registre limitações e decisões metodológicas;
- mantenha supervisão humana sobre decisões sensíveis;
- não reutilize músicas, imagens ou marcas de terceiros sem autorização.
