# Contribuindo

Este projeto é um laboratório universitário em desenvolvimento. Sugestões de melhoria são bem-vindas, especialmente quando tornam o método mais claro, reproduzível e reutilizável por outros estudantes.

## Antes de propor uma alteração

- explique qual problema acadêmico ou técnico a alteração resolve;
- preserve a separação entre dados simulados e observados;
- não adicione documentos avaliativos reservados ou dados pessoais;
- não inclua credenciais, chaves de API ou arquivos `.env`;
- considere acessibilidade e comportamento responsivo.

## Validação local

```bash
pnpm install
pnpm check
pnpm build
```

## Estilo de commit

Prefira mensagens curtas e descritivas, por exemplo:

- `feat: adiciona exportação de experimentos`
- `fix: preserva proporção das imagens do cartão`
- `docs: esclarece limites dos dados simulados`

## Escopo de autoria

Contribuições de código não transferem direitos sobre músicas, letras, vozes, imagens, marcas ou outros ativos artísticos do projeto Dvorah. Alterações acadêmicas relevantes devem ser descritas na documentação para manter a rastreabilidade do trabalho.
